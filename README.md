# ocg-website
Orion Contingency Group Inc. public website - www.orioncontingencygroup.com

## Updating the site

All changes go through this repo; the live site at www.orioncontingencygroup.com is deployed from `main` by GitHub Pages. Squarespace holds only the domain and mail records.

- Text fixes: edit the file in the GitHub web editor and commit to `main`.
- Content or structural changes: branch, pull request, review the diff, merge.
- Record every content change in `CHANGELOG.md` with the source document it was checked against.
- Content sources: current capability statement (Drive), course syllabi (Drive, OIT / Training Courses), cadre roster with publication consent on file.
